# Stanley Dirk Nente – Portfolio

A static portfolio site (plain HTML and CSS, no build step).

## Files
- `index.html` – the whole page
- `assets/` – project screenshots

## Deploy on GitHub Pages
1. On GitHub, create a new **public** repository.
   - For a URL of `https://stanley3322.github.io`, name it exactly `Stanley3322.github.io`.
   - Any other name also works; the site will then live at `https://stanley3322.github.io/<repo-name>/`.
2. Upload everything in this folder (`index.html`, `assets/`, `.nojekyll`, `README.md`) to the repository root.
3. Go to **Settings → Pages**. Under **Build and deployment**, set **Source** to *Deploy from a branch*, choose branch `main` and folder `/ (root)`, then **Save**.
4. Wait 1 to 2 minutes. The site URL appears at the top of the Pages settings.

## Editing
- Change text directly in `index.html` (search for the section you want).
- Replace or add screenshots in `assets/` and update the `<img src="assets/...">` lines.
- Commit the change and GitHub rebuilds the site automatically.
